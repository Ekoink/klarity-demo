# Klarity Health Refill Request Dashboard

Built for the Klarity Health hackathon, May 2026.

This is a prototype of an AI-powered refill request dashboard for Klarity's provider portal. It assesses incoming patient medication refill requests and gives providers a plain English recommendation on whether to approve the refill or ask the patient to book a visit first.

Live demo: https://ekoink.github.io/klarity-demo
